# 实施路线

各阶段以产物和验收结果推进，不按日期假设完成。

| 阶段 | 任务 | 完成条件 | 状态 |
| --- | --- | --- | --- |
| P01 | 主机协议模拟 | 覆盖合法、超长、重复、忙态、超时输入；不需要相机或板卡。 | 未开始 |
| P02 | 恢复最小可构建依赖 | 建立独立项目，锁定摄像头与模型版本，输出构建记录；不宣称板上可用。 | 未开始 |
| P03 | 单板 Fake 触发 | 20 次顺序事件都有对应终态；有人/无人都记录结果；无 RTSP 客户端也可取帧。 | 未开始 |
| P04 | 外部触发适配 | 先用模拟源，再按需接传感器；验证事件键、重启和丢包，不更改视觉算法。 | 未开始 |
| P05 | 按需感知评估 | 对比周期运行与事件运行，记录漏检、响应延迟、活动占空比；能耗需仪器实测。 | 未开始 |

研究拓展：研究触发式观察的收益与漏检代价；不同触发源采用相同视觉模型和场景，避免把视觉精度变化误归因于触发策略。

每轮提交同时更新学习笔记、实验结果与下一步。失败结果保留，并说明条件。
