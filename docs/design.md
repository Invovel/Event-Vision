# 设计与模块

## 目标

把外部触发归一化，在本地取一帧并执行行人检测，返回同一事件键的结果或错误。触发源可替换，视觉处理不依赖 CSI。

数据路径：Fake/PIR/外部触发 → 协议校验 → 单事件闸门 → 取帧 → 行人检测 → 坐标还原 → 终态回包

| 模块 | 责任 |
| --- | --- |
| trigger | 输入适配与字段校验；USB 调试和业务 UART 分开 |
| gate | 单在途事件、忙态拒绝、最近完整终态缓存 |
| vision | 独立取帧、推理、原图坐标还原与资源释放 |
| result | 同一 boot_id/event_id 的 result/error；空检测也是正常结果 |

## 接口初稿

沿用历史语义作为候选基线：JSONL、单行最多 1024 字节含换行；v/kind/boot_id/event_id/source/level。忙态返回 vision_busy，已受理事件返回 vision_result 或 vision_error；同键完成后重发缓存终态，不再取帧。坐标为空间 camera，携带原图 image_size。缓存仅保证当前进程最近一条，不保证断电 exactly-once。

以上是设计约定，不代表已有可互通实现。冻结接口时增加样例、边界条件和版本迁移说明。

## 范围

不研究 CSI 信号、不做手势意图识别、不控制执行器；首轮不要求 RTSP 与推理并行。
