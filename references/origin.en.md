# Design origin and reference management

[中文](origin.md) | English

This repository turns the user's “Event-Driven Visual Verification” concept into an independent design and learning starting point. The documentation framework was created on October 13, 2026; implementation is pending.

Goals, draft interfaces, stages and experiments are described here in full. No external project documents are required to begin. No third-party source code, private configuration or device backups have been imported.

For future references or code, record title, URL, pinned version or commit, license, adopted scope, modifications and validation date. Current upstream compatibility has not been verified; candidate components are not yet selected dependencies.
