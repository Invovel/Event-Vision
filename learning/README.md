# 项目驱动学习路径

每阶段按“问题 → 原理 → 最小实验 → 观察 → 解释与局限”记录。

## P01：主机协议模拟

学习任务：覆盖合法、超长、重复、忙态、超时输入；不需要相机或板卡。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P02：恢复最小可构建依赖

学习任务：建立独立项目，锁定摄像头与模型版本，输出构建记录；不宣称板上可用。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P03：单板 Fake 触发

学习任务：20 次顺序事件都有对应终态；有人/无人都记录结果；无 RTSP 客户端也可取帧。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P04：外部触发适配

学习任务：先用模拟源，再按需接传感器；验证事件键、重启和丢包，不更改视觉算法。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P05：按需感知评估

学习任务：对比周期运行与事件运行，记录漏检、响应延迟、活动占空比；能耗需仪器实测。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

资料按当前任务补充，不先堆积整套课程。
