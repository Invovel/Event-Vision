# Event-Vision · 事件驱动视觉验证

中文 | [English](README.en.md)

收到外部事件后，如何按需观察，并返回与该事件对应的可信结果？

把外部触发归一化，在本地取一帧并执行行人检测，返回同一事件键的结果或错误。使用软件模拟触发即可独立开始，不依赖特定传感器。

状态：2026-10-13，设计起始库。尚未实现新固件、训练模型或开展硬件验收。

## 独特目标与范围

首版只完成触发、单帧检测和关联回包；不推断用户操作意图、不控制执行器，也不要求 RTSP 与推理并行。

本库可独立推进，包含自身的设计、学习路径与实验计划。通过测量积累实现证据，未做过的实验不写成成果。
