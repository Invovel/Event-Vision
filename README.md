# Event-Vision · 事件驱动视觉验证

收到外部事件后，如何按需观察，并返回与该事件对应的可信结果？

把外部触发归一化，在本地取一帧并执行行人检测，返回同一事件键的结果或错误。触发源可替换，视觉处理不依赖 CSI。

状态：2026-10-13，设计起始库。尚未实现新固件、训练模型或开展硬件验收。

## 独特性

不研究 CSI 信号、不做手势意图识别、不控制执行器；首轮不要求 RTSP 与推理并行。

本库保存设计、学习过程和后续实现；不通过复制整套历史文件伪造完整工程。实验完成后才更新状态。
